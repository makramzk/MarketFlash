# 📊 MarketFlash: Marketing Services

## 🏢 About MarketFlash
MarketFlash is a newly established marketing company. The owner, Markus, aims to leverage data-driven insights to enhance business performance.

## 🎯 Project Overview
Markus approached us to develop a Database and Dashboard that provide valuable insights into marketing performance. The project focuses on tracking key metrics across different channels, audience segments, and locations.

## 📌 Key Requirements
Database Development

Design and implement a Functional ER Diagram
Store and manage data related to marketing campaigns, customer demographics, and performance metrics
Dashboard Implementation

Visualize marketing performance by channel
Analyze audience engagement
Assess location-based performance trends

## 🛠️ Tech Stack
Database: SQL (MySQL / PostgreSQL)
Dashboard: Tableau 
ETL & Data Processing: SQL, (MySQL)
## 📂 Repository Structure
database/ → ER Diagram, SQL scripts
dashboard/ → Dashboard files & visualizations
data/ → Sample datasets
docs/ → Documentation & user guide
## 🚀 Outcome
This project equips MarketFlash with an efficient data infrastructure and a powerful dashboard, enabling data-driven marketing decisions.
